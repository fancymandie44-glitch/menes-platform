Ta machine Square = paiements en personne. Pour le site web, on utilise l'API Square (même compte, même argent).

Comment obtenir tes clés Square (gratuit):

  1. Va sur developer.squareup.com/apps
  2. Crée une application → copie Application ID
  3. Credentials → Access Token + Location ID
  4. Colle-les ici → les clients pourront payer sur le site

💡 L'argent arrive sur le même compte que ta machine Square. Tu reçois les notifications dans l'app Square Seller sur ton téléphone.
