MENES Platform — Alternative gratuite à Shopify. Gère plusieurs marques, domaines, produits, commandes et paiements depuis une seule console.

Boutiques & marques

Crée une boutique pour chaque marque. Chaque boutique a ses propres produits, design et domaines.

Domaines

Référence les adresses de chaque boutique. Pas besoin de les ajouter dans Netlify → boutiquemenes si c'est un autre projet Netlify (ex: Grillz).

🦷 Site sur un autre projet Netlify (ex: MENES Grillz)

Chaque projet Netlify a déjà son URL (xxx.netlify.app). Tu ne lies pas le domaine Grillz dans boutiquemenes.

  1. Console → Boutiques & marques → crée « MENES Grillz »
  2. Ici, ajoute menesjewelrygrillzprice.netlify.app comme domaine de référence
  3. Sur le projet Grillz, déploie avec grillz-site/DEPLOY-GRILLZ.bat
  4. Gère produits et design depuis l'admin en sélectionnant « MENES Grillz »

Domaines — MENES

Domaine personnalisé (mybrand.com)

  1. Ajoute le domaine ici (ex: mybrand.com)
  2. Va sur Netlify → le projet de cette boutique → Domain management
  3. Clique Add domain et suis les instructions DNS
  4. Attends 5–30 min pour la propagation DNS
