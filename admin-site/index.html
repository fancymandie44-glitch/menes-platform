Site sur un autre projet Netlify (ex: MENES Grillz)

Chaque projet Netlify a déjà son URL (xxx.netlify.app). Tu ne lies pas le domaine Grillz dans boutiquemenes.

  1. Console → Boutiques & marques → crée « MENES Grillz »
  2. Ici, ajoute menesjewelrygrillzprice.netlify.app comme domaine de référence
  3. Sur le projet Grillz, déploie avec grillz-site/DEPLOY-GRILLZ.bat
  4. Gère produits et design depuis l'admin en sélectionnant « MENES Grillz »

Paiements

Les clés secrètes ne s’affichent jamais ici. Configure chaque provider dans Netlify → Site settings → Environment variables (site boutique), puis redéploie. Une variable absente = méthode non disponible au checkout.

Carte · Stripe

Checkout hébergé Stripe. Requis : STRIPE_SECRET_KEY.

Statut : configuré si la clé est définie dans Netlify ; sinon indisponible.

Square

Carte / wallet via Square. Requis : SQUARE_ACCESS_TOKEN + SQUARE_LOCATION_ID.

Statut : configuré si les deux variables sont présentes.

PayPal

Requis : PAYPAL_CLIENT_ID + PAYPAL_CLIENT_SECRET.

Statut : configuré uniquement avec les deux secrets Netlify.

Klarna

Via Stripe (/paiement.html). Même clé STRIPE_SECRET_KEY.

Disponible si Stripe est configuré.

Crypto

Adresses publiques dans Design → Wallets crypto. Aucune clé secrète Netlify.

Actif dès qu’au moins un wallet a une adresse.

Exemple CLI : git push puis netlify deploy --prod (ou laisse le build Git connecté faire le travail).
