SQUARE : RECEVOIR L'ARGENT
--------------------------

Ta machine Square = paiements EN PERSONNE seulement.
Pour le SITE WEB, tu utilises l'API Square (même compte):

1. Va sur https://developer.squareup.com/apps
2. Crée une app → copie Application ID + Access Token + Location ID
3. Dans l'admin → onglet Paiements Square → colle les clés
4. Dans Netlify → Site settings → Environment variables:
   SQUARE_ACCESS_TOKEN = ton token
   SQUARE_LOCATION_ID = ton location ID
   SQUARE_SANDBOX = true (pour tester) ou false (production)

L'argent va sur le MÊME compte que ta machine Square.
Tu reçois les notifications dans l'app Square Seller sur ton téléphone.
